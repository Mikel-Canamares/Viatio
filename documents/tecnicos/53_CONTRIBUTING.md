# Contributing

## Flujo de trabajo (propuesto)
- Branches por feature/bugfix.
- PR con revisión y checklist.

**Nota**: NO ENCONTRADO EN CÓDIGO un estándar de ramas oficial.

## Checklist de PR
- [ ] Compila sin errores.
- [ ] Variables de entorno documentadas.
- [ ] Cambios de DB con migración.
- [ ] Impacto en sync revisado.
